## 二、逐项证据

### 2.1 首页主按钮（`.primary-button .start-submit-button` 开始排盘）

CSS 现状（`src/styles.css:6147-6165`）：
- ✅ base：渐变底 + cursor: pointer + box-shadow
- ✅ `:hover`：背景变 `var(--accent-deep)`
- ❌ `:active`：无（点击无按压反馈）
- ❌ `:focus-visible`：无（键盘用户无焦点环，WCAG 2.4.2 不达标）
- ❌ `:disabled`：无（但主按钮也从不 disabled，见下）
- ❌ loading 态：无

**点击反馈缺陷**：`submitBusy`（InputPage.tsx:72）只用于渲染全屏 `SubmitProgress` 步骤动画，**从未绑定到主按钮**——
- 按钮无 `disabled={submitBusy}` → 动画期间可重复点击（handleSubmit 无重入锁，二次点击会再 saveProfile + trackChartSubmit + 再起一套动画）；
- 无 `aria-busy` / `aria-disabled` → 屏幕阅读器无感知。

注：SubmitProgress 本身实现良好（role="status" + aria-live="polite"，逐步点亮后 onDone 回调跳转）。

### 2.2 表单错误反馈（`setError` → `.form-error-text`）

- 校验链完整：空年月日 / 时辰 / 真太阳时 / 出生地 / 合婚第二人，共 8 段前置校验（InputPage.tsx:303-389），文案具体（"请填写完整的个人信息"级别）。
- ❌ 错误 div（InputPage.tsx:637）**无 aria-live / role="alert"**——视觉用户看得到，读屏用户完全无感知。
- 无 `aria-invalid` 标记对应输入框（无障碍加分项，非阻塞）。

### 2.3 /result 页 CTA 按钮

`ResultPage.tsx:162-266` 全部为**内联 style** 按钮：
- 4 个 AI 问题按钮（"今年什么时候该出手？"等）：无 hover / active / focus 任何态；
- "重新排盘" / "查看大运"：同上；
- **付费 CTA "立即升级会员 →"**：渐变底但零交互态——这是 T6 付费转化按钮，点击无按压反馈、键盘无焦点环。

### 2.4 操作连贯性（✅ 基本通）

- 链路完整：/ → 提交 → SubmitProgress（有序步骤动画）→ /result → 大运/流年/定价，无断点；
- `RelatedNavLinks`（"继续探索"）功能矩阵存在；
- 档案自动保存（saveProfileFromForm，H02 "一次录入自动复用"）与历史页 /records 联通；
- trackChartSubmit 埋点（T0 漏斗）在提交时触发。

### 2.5 移动端（🔴 P0，截图实锤）

`shots/home_mobile.png`（390×844）：
1. **顶部导航栏文字裁切**：排盘/合盘/占卜/择日 tab 溢出，"占卜" 只剩半个字；
2. **"管理档案" 按钮文字竖排断行**（每字一行），按钮宽度未约束 min-width；
3. 桌面端 `home_desktop.png` 同样存在"管理档案"竖排——说明是组件级布局 bug，非响应式问题；
4. hero 星空条：桌面/移动端都只是一条**灰紫色渐变条**，无星星、无星空——与 P0-4（星空首屏落空）同源。

## 四、修复建议（不代执行，等老板放行）

1. **IA-1（P0）**：给"管理档案"按钮加 `white-space: nowrap; min-width`；顶部导航移动端改折叠或降字号/加 gap 约束。
2. **IA-2**：主按钮加 `disabled={submitBusy}` + CSS `:disabled` 态；`.primary-button` 补 `:active { transform: translateY(1px) }` + `:focus-visible { outline: 2px solid var(--accent-strong) }`。
3. **IA-3**：error div 加 `role="alert" aria-live="assertive"`。
4. **IA-4**：Result 页按钮抽公共 class（如 `result-cta`），补 hover/active/focus 态；付费按钮加 `:active` 缩放反馈。
