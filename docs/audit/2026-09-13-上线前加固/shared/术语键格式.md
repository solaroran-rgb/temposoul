# 共享规范 · archetype_key 与术语键接口约定（T2/T3 引用）

> 版本 v1 ｜ 2026-09-13 ｜ T4 出品

## archetype_key（排盘实体主键）

- 形态：`<体系>:<实体类型>:<实体名>`，全小写蛇形，如 `bazi:shishen:zheng_guan`、`ziwei:star:ziwei`、`astrology:planet:saturn`。
- 来源：白皮书 2.1「证据型输出 /archetype_key 命名」；引擎侧 evidence 结构已内嵌 owner key（`build-evidence-pool.ts`）。
- 规则：**键即契约**——T2 词库锚定、T3 术语查表都以 key 关联；改键 = 破坏性变更，须四线程会签 + 更新日志。

## 术语键（lexicon 词条关联）

- 词库：`src/data/lexicon.ts` + `lexicon-extra.ts`（1180 条）。词条以 `key` 关联 archetype_key 或独立术语键 `term:<域名>:<slug>`。
- T3 翻译规则：排盘内容输出必须经 `key → 译文` 查表；查不到 = 缺词条（先补词库，禁 LLM 直译关键术语）。
- 7 语言 locale 文件（`src/i18n/locales/{zh-CN,en,ja,ko-KN,es-ES,th-TH,vi-VN}.ts`）只承载 UI 文案（134×7）；排盘内容翻译走 lexicon，两轨不得混用。

## 版本与变更

- 键表快照随每个黄金样例库版本落盘（`cases/_keys_snapshot.json`），保证评测可复现。
- 新增键：先本文件登记格式样例，再进词库/引擎，写入顺序 = 引擎 → 词库 → 本文件。

## A8 term_refs 绑定契约（T-17 子项 B，2026-10-08）

- 引擎轨 `term:<域>[:<子类>]:<slug>`（52 键，见 `mapping库_v1/term_keys_v1.json`）→ 词库轨 lexicon key `<namespace>:<term>`（T-14 冻结，尾段=term）。
- 绑定规则：剥离子类段后按 pinyin 规范化匹配 lexicon（`pinyin` 字段去声调/空格/连字符），多候选按 disambiguation（所属排盘体系）实算择一，禁止猜测。
- **孤儿 = Critical**：绑不上的 `term:<域>:<slug>` 登记 `A8_ORPHAN_REFS`（本次 11 条），须补词库后方可上线；缺词条时查表返回 null/明确信号，**禁止 LLM 直译关键术语**。
- 跨文件同名多义（lexicon.ts ∩ lexicon-extra.ts = 17 term）在 `src/data/mappings/a8-polysemy.ts` 注册消歧 key `<namespace>:<term>_<sense_id>`；不改 lexicon 本体（K4-1 断言 key 尾段=term）。
