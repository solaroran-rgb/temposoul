## 启用变量（CF Pages → Settings → Environment variables，Production）

| 变量 | 值 | 说明 |
|---|---|---|
| AI_API_KEY | （用户提供，sk-…） | **唯一外部依赖：DeepSeek 充值后创建 key** |
| AI_BASE_URL | `https://api.deepseek.com/v1` | 默认值，OpenAI 兼容 |
| AI_MODEL | `deepseek-chat` | 可后续换 |
| AI_BUILTIN_ENABLED | `true` | 前端显示并允许内置 AI（不设则仍隐藏） |
| AI_DEFAULT_ENABLED | `false` | 页面默认不开 AI 解读（公益服务不稳定建议 false） |

## 执行步骤（拿到 key 后 10 分钟）
1. 用户充值 DeepSeek 并创建 API Key（预算建议：MVP 验证期 ¥50-100 封顶，deepseek-chat 约 ¥1/百万输入 token）
2. `wrangler pages secret put AI_API_KEY --project-name temposoul`（其余 4 个非密变量走 Dashboard vars 或同样 secret）
3. 触发重部署（或等下次部署自动生效）
4. 验收：①`curl /api/v1/ai/analyze` 200 流式返回 ②响应 meta 含 compliance/dict_version/model_version 三元组 ③无 key 访客（隐身窗）可用 ④危机样句触发线程2 危机热线文案（联测 T2-01）

## 风险与边界
