## 3. 本轮改动清单（全部落在 worktree，未提交、未部署）

### 3.1 根因修复 · 观测者锚点（`SkyScene.ts`）

新增单一事实源 `FIG_Z = 113.5`，替换散落的 104.5（人形 group / ENERGY_ORIGIN），并同步到 `GROUND_GLOW.cz`、`LIGHT_SHAFT.z`。

解析反解（冻结相机 `pos(0,58,200)` / `lookAt(0,20,-160)` / fov 58 垂直 / 16:9）：

| z | 脚底屏位 | 头顶屏位 | 屏高 |
|---|---|---|---|
| 104.5（旧） | 92.5% | 86.0% | 6.5% |
| **113.5（新）** | **97.8%** | **90.6%** | **7.2%** |
| 114.16 | 98.0% | — | — |

规范 V15/V20 要求 脚底 98.35% / 高 7.33% ⇒ 新值归位。

### 3.2 地平线辉光带（`renderTokens.HORIZON_GLOW` + `atmosGlow.ts`）

- 光带平面 z 由硬编码 60 → **85**（原先被 z=69/84/93/101 四层楼按 ~70% 覆盖率切碎，带心永远只亮在楼缝里）
- 带心 y 20 → **21.5**（投影 71%）；`skySigma` 4.5 → **2.2**（CT-1 的带是"66%→70% 陡升"，天侧须近截断）
- `groundSigma` 22 → **16**；`peak` 0.17 → **0.16**

### 3.3 地脚光池（`GROUND_GLOW`）

- 由各向同性 σ 改为**椭圆**（`poolSigX=12 / poolSigZ=9`）：X 宽 Z 窄，才能"脚下亮 + 前景暗"同时成立
- `poolPeak=2.4`（刻意过饱和成实心亮盘）；颜色向 `text-bright` 混 30%（去掉"荧光青板"感）

### 3.4 城市纵深收窄（`geoEngine.buildSolidCity`）

8 层 TIERS → 6 层，近端由 z=113 **收到 z=101**。理由：420 对拍裁图证明 CT-1 的 98% 行亮的是**地脚光池不是楼**；原先"把城市铺满 68%–100%"是对基线的误读，代价是画面下三分之变成俯视灯毯。

### 3.5 窗光（`SOLID_CITY`）

`winPitch` 1.15/1.05 → **0.72/0.66**；`winLit` 0.45 → **0.34**；`winGain` 1.50 → **1.25**（窗变细变疏变暗）。

### 3.6 星云 / 星云带（`atmosGlow.NEBULA_FRAG`）

轴高 240 → **150**（整体下移）；带宽 σ 85 → **60**；`uPeak` 0.30 → **0.45**。

### 3.7 UI（`SkyPage.tsx`）

`.ui-t1` 28→38px、`.ui-sub` 20→27px，两档 media query 同步等比放大。
