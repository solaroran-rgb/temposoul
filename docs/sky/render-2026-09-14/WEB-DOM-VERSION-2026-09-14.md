## 二、更正后的正确路线

**背景用资产层，文字全部用真 DOM。** 页面结构：

```
#stage
└─ #web                        ← 设计稿坐标系（宽高比恒 1.981424）
   ├─ <img id="scene">         ← L0 资产层（文字剥离的场景层，多档位/多格式）
   ├─ <canvas id="fx">         ← L2 动态层（星点微光，可关）
   └─ #ui
      ├─ <h1>命律 TempoSoul</h1>        ← 真 DOM
      ├─ <p>探索命运的节律</p>            ← 真 DOM
      └─ <a href="#start">立即开始</a>    ← 真 DOM（可点击/可聚焦）
```

外加真实网页应有的 `<title>` / `meta description` / `og:*` / favicon。

### 2.1 关键修复：一个半像素引发的全图错位

上一版把 `#web` 用 `transform: translate(-50%,-50%)` 居中。当 `#web` 高为 **969（奇数）** 时，`-50% = -484.5px` 是**半像素**，触发整层重采样 → 全图每个像素都被插值改过。

| 指标 | 修复前 | 修复后 |
|---|---|---|
| 全图逐像素一致 | 43.45% | **91.10%** |
| 背景区逐像素一致 | 53.01% | **98.89%** |
| 背景带 y[484,969) | — | **100.0000%** |

**改法**：禁 `transform` 居中，改负 margin：
```css
#web{margin-left:calc((100vw - max(100vw,calc(100vh*1.981424)))/2);
     margin-top:calc((100vh - max(100vh,calc(100vw/1.981424)))/2)}
```

### 2.2 文字层：位置/跨度/字高全部对齐

设计稿是 AI 出的艺术字，系统字体在同字高下**宽约 17%**。用**合成窄化 `scaleX`** 反解倍数，使「横向跨度 == 设计稿跨度」且「字号（字高）保持设计稿量级」同时成立：

| 元素 | 渲染实测 | 设计稿实测 | 差 |
|---|---|---|---|
| 主标题 | 宽 **645**，中心 (54.818%, 16.512%) | 宽 645，中心 (54.818%, 16.512%) | **0** |
| 副标题 | 宽 **390**，中心 (50.000%, 25.800%) | 宽 390，中心 (50%, 25.8%) | **0** |
| CTA 按钮 | **290 × 104**，中心 (51.562%, 39.627%) | 290 × 104，中心 (51.562%, 39.628%) | 0.001% |

自适应倍数实测：标题 `scaleX 0.8324` ｜ 副标题 `0.9545` ｜ CTA `1.1728`。

## 四、诚实的取舍（必须您拍板）

**「像素 100% 一致」与「真网页」在物理上互斥**：

| 方案 | 视觉一致度 | 是不是真网页 |
|---|---|---|
| A 纯图片（上一轮做法） | **100%** | ❌ 文字在像素里，无 DOM、不可索引、不可改文案、无障碍读不到 |
| B **背景资产 + 真 DOM 文字（本版）** | 背景 **98.89%** / 全图 91.10% | ✅ 可索引 / 可复制 / 可响应式 / 可多语言 |
| C 背景资产 + web font 复刻字体 | 目标 ≥ 95% | ✅ 需您提供设计稿字体名与授权（**P11**） |

**我的建议：B 上线**，同时推进 C（拿到字体后字形差会显著收敛）。
