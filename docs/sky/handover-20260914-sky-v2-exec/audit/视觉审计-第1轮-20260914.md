## 4. 关键结论（两条）

### 4.1 相机契约无冲突 —— 68% 是「城市天际线基座」而非「地面消失线」

解析投影（冻结相机，pitch = atan(38/360) = **−6.03°**，fov 58°）给出地面上一点 `(0,0,z)` 的屏显画高比例**单调映射**：

```
z=+190 → 100%      z=+104.5 → 98.35%   z=+72 → 82.9%    z=+32 → 72.4%
z=+8  → 68.3%      z=+5 → 67.9%        z=0 → 67.2%      z=−70 → 59.6%
z→−∞  → 40.5%（地面消失线）
```

- 若把 68% 误读为「地面消失线」，则**数学上不可能**：消失线只能到 40.5%，与俯角无关的是 pitch、不是 z。
- 正确读法：§3.1/§3.3 的 68% 是**①③ 分区线**，即地貌带（山脊/城市）的**起始行**。冻结相机下 `z≈+5` 恰好落 68.3%，**§11 契约本身自洽**。
- （旁证）Taipei tile 载荷以观测点为原点，城市天然在 `z≈0` → 67.2%，也正是此处。§11 冻结相机正是为此选定。

**真因**：`buildAbstractSkylinePayload()`（非 Taipei 覆盖区的默认载荷，济南 36.65/117.12 走此路）把天际线**单层**钉在 `z=80` → 基座屏 **81.3%**，地平线整体下沉 13%。p5/p7 已修正为 6 层纵深、基座 70.2%→99.0%、远层塔顶 67.3%（越线 0.7% ≤ §6.7 允许的 3%）。

### 4.2 检测器必须用冻结基线反标定

V13 的测法「行均值 + 分区检测」在遇到**细线稿**介质时会失效：15×15 盒滤会把 2px 线稿抹到阈值以下（实测 D3 读到 75.6%，而城市肉眼起点在 62–65%）。改用**与介质无关**的 D5「非纯黑像素占比（L\*>8）@10% 阈值」，并以冻结基线 CT-1 的**已知真值 68.01%** 反标定偏置：

```
CT-1  D5@10% = 65.22%  →  偏置 = 68.01 − 65.22 = +2.79%
实现  D5@10% = 65.65%（桌面）/ 65.52%（移动）  →  标定后 68.43% / 68.25%
```

同一检测器下 **实现与 CT-1 相差 0.43% / 0.30%**，远在 ±1% 容差内。
