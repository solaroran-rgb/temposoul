## 一、网站是什么 & 哲学主题风格（第一部分：这件事的灵魂）

### 1.1 产品定位

- **TempoSoul·命律** —— 全球**真太阳时**排盘网站 / Web App（PWA），生产环境 `www.temposoul.com`。
- 商业链路：**神秘文化引流 → AI 分析建信任 → 订阅/电商变现**。
- `/sky` 是**首页/星空首屏**，在信任漏斗（T0-T6）中承担 **T0「星空首屏 0-5 秒第一眼信任」**——它是全站的门面，这就是为什么老板对它零容忍。

### 1.2 品牌哲学（白皮书原话，文案与视觉都必须服从）

- 贩卖「**已知的从容**」，而非「未知的恐惧」。
- **命 = 生命轨迹**（服务对象）；**律 = 宇宙法则 / 算力**（技术底座）。
- **Tempo = 客观物理世界**（真太阳时 / 节气 / 行星）；**Soul = 主观意识世界**（自性化 / 疗愈）。
- 定位「**生命源代码与时空节律图**」；**拒绝「算命 App」标签**。
- 品牌主标题「**命律 TempoSoul**」，副标题「**探索命运的节律**」，CTA「立即开始」。

### 1.3 视觉北极星（规范 §1，一字不改）

> **「这不是『数据可视化』，这是一张『人在宇宙中渺小』的数字哲学海报；数据只是它的颜料，不是它的目的。」**

三条公理（可判定）：

| 公理 | 含义 | 可判定表述 |
|---|---|---|
| **A1** | 黑是主角，光是客人 | 全画纯黑（亮度 < L\*8）≥ **62%**；任一 64×64 块均亮 ≤ L\*45 |
| **A2** | 层级分明，无平铺 | 一眼读出「星空 > 地貌 > 城市 > 人物 > 细节」五级层次，相邻级峰值亮度差 ≥ 25% |
| **A3** | 克制高于丰富 | 每新增一个视觉元素，必须先移除或压暗一处已有元素 |

### 1.4 风格基因（青黑科幻 + 东方命理）

- 单色青光（色相 186°–192°）+ 纯黑底；一切光带泛光衰减（r^-1.6）。
- 粒子/点阵构成主体；垂直中轴光柱（x=50%，天顶→人形）；微型技术注释文字（11px/字距 0.2em）。
- **全画唯一暖色焦点 = 月亮**（#F0C878，≤0.8%，单簇）；星座连线 α 0.06–0.08（极弱）；中文-only 星座标签。
- **硬禁令**：卡通/手绘/油画/水彩 ❌｜写实照片/3D 实体渲染/立体光影 ❌｜阴影 ❌｜恐怖符号（血月/骷髅/发光眼睛）❌｜<2s 周期闪烁 ❌｜文字水印 LOGO 边框 ❌。
- **真实数据是灵魂，也是红线**：5044 颗真实星表（`stars.data.ts` 151KB）、真实月相（某些时刻正确地"无月"）、真实 OSM 城市建筑 + 108,525 城市库、真实 DEM 山脊等高线、`/api/locate` IP 定位。这是它与"AI 猜图"的本质区别——**画面必须长在真数据上**。

## 四、核心矛盾（为什么判据全绿还是"简笔画"）——不读这节必重蹈覆辙

1. **规范自相矛盾是根因**：规范 §6.6 明令城市「纯线框 + 窗格点阵，**禁止实体填充**」，但 **CT-1 标准样图本身就是实体填充的插画城市**（V24 实测 36.06，是纯线稿天然能达到的 3–9 倍）。只要 §6.6 不修订，地貌带永远到不了 CT-1 观感。
2. **介质天花板已被两轮实测**：程序化线框/线框+低α面片，逼近 AI 高密度位图插画的观感天花板在 40–60%（两代执行者独立得出同一结论）。
3. **三条路都走过、都被否**：①AI 生图整图拼接（欺骗式交付，红线）；②Canvas 照描位图（天花板）；③WebGL 纯线稿+面片（简笔画感）。**老板要的是第四条路：既有实体插画的质感，又长在真实数据上、真 WebGL 渲染。**
4. **接手者第一件事 = 推动老板做方向拍板**（拿对拍图去问，不要闷头调参）。三个候选方向：

| 方向 | 内容 | 代价/风险 |
|---|---|---|
| **甲：修订 §6.6** | 允许"程序化实体感"——建筑画实心挤出体+自发光窗格+距离雾+辉光，仍由 OSM 真实数据驱动、纯 WebGL 生成 | 需老板点头改规范；质感上限取决于着色器功力 |
| **乙：WebGL 内用高质感纹理资产** | AI 生成建筑/天际线 sprite 或纹理图集（带 Alpha），真实数据只负责**布局与遮挡**（哪个位置放哪栋楼） | **必须先裁定是否触碰 §12 红线**（"AI 猜图静态方案"禁的是整图静态化，局部纹理资产属灰色地带）；性能需预算 |
| **丙：老板出新标准样图** | 接受当前介质上限，出一张程序化可达的新样图再收敛 | 视觉期望降级，老板未必接受 |

5. **明确不可做**：整图 `<img>` 拼接页面（红线 + 已两次被老板点名）；未经拍板自行选边。
