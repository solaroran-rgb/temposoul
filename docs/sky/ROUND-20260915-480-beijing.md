## 四、关键修正链（8 轮迭代，每轮均有截图与剖面证据）

| # | 现象 | 根因 | 修正 |
|---|---|---|---|
| 1 | 城市成"发光地毯" | 真实建筑线性换算后仅 1.3–2.6u 高 → 实体不可见，只剩贴地顶环线 | 高度改幂 0.55 压缩 + 下限，低层抬成连续暗体 |
| 2 | 中层环铺成贴地亮线毯 | L1 环画在 `y=0`（地面），940 栋首尾相连 | L1/L2 环改画在楼顶 `y=h` |
| 3 | 整片青蓝发光团 | 真实尺度下窗格数量级远超抽象城市 | `winGain` 1.25→0.55→0.38、`winLit` 0.34→0.16 |
| 4 | 满屏"短横线" | 940 栋逐栋勾顶环+竖棱 | 只有 ≥60m 的塔才勾线 |
| 5 | 楼呈"竖条纹柱" | **宽高比失真**：高度走了幂压缩、宽度却是线性的（真实 5.5:1 被拉成 10.9:1） | 底面 ×1.6 + 下限 2.6u，比例回到 ~6.7:1 |
| 6 | 带区（51–68%）超亮 +101% | 城市从画面 40% 铺到 100%，侵入地平线辉光带 | tile 平面标定：纵向压缩 + 整体前移 |
| 7 | 峰值落在 64%（CT-1 在 70%） | 城市带偏高 | `TILE_Z_SCALE/OFFSET` 三轮标定至 0.22 / +76 |
| 8 | 塔顶直插 60% | CT-1 城市是**扁平剪影带**，塔高只占带厚一小部分；我做到 28u → 占 21% 画高 | 高度系数 1.3→0.9→（幂 0.35×1.6） |

**平面标定反解公式**（相机 `y=58 / lookAt(0,20,-160) / fov 58°`，`D = 200 − z′`）：

```
画面 y% = 0.5 + 0.5 · tan(6.02° − atan(58/D)) / tan(29°)
68% ⇒ D=190 ⇒ z′=−10 ；90% ⇒ D=100 ⇒ z′=+100
```
