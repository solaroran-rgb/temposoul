## 二、CSV 字段

| 字段 | 含义 |
| --- | --- |
| `key` | 术语标识（tier1 为 `archetype_key`，tier2 为 `tier2:<前缀>:<slug>`） |
| `zh` / `pinyin` / `category` | 中文原词、汉语拼音（文化概念保留拼音作溯源）、所属门类 |
| `en` | 英文基准译名（tier1 已定，本表以它为口径锚点） |
| `ja` / `ko` / `vi` / `th` / `es` | 五语规范译名 |
| `basis` | 该条译名的处理依据（音读/意译/汉越词/音译、是否待母语复核） |
| `status` | `tier1_filled`（一期已定稿）/ `filled`（五语齐备）/ `partial`（尚有语种空缺）/ `tier2_pending`（待补） |

## 三、文化特有概念处理策略（核心口径）

### 3.1 总原则

1. **锚定 zh / en**：同一概念在五语下必须同源。若正文译文与术语表冲突，**以术语表为准**回滚正文。
2. **只译不改**：术语译名不承载新增语义、不弱化免责口径。
3. **首见标注**：音译类概念在正文首次出现时允许加括号原文（如 es 的 `Ba Zi`），后续行文可直接用译名。
4. **机器可校验**：术语表中的汉字文化词进入 `KEEP_HAN` 白名单，作为 vi/th/es「汉字残留」校验的豁免项。

### 3.2 分语种策略

| 语种 | 策略 | 示例 |
| --- | --- | --- |
| **ja** | 汉字文化圈：命理术语**保留汉字原词**，读音按日语汉音/习惯读法；长句用日语书面语，禁用中式直译句法 | 八字＝八字（はちじ/そうじ按词固定）、紫微斗数（紫微斗数）、天干/地支、十神、大运/流年、神煞、纳音 |
| **ko-KN** | 沿用汉字词 + 韩式汉字音（`팔자`＝八字、`자미두수`＝紫微斗数、`천간/지지`＝天干/地支、`십신`＝十神、`대운/세운`＝大运/流年） | 塔罗牌名沿用既有译名，不新造 |
| **vi-VN** | **汉越词**为主体：Bát Tự（八字）、Tử Vi Đẩu Số（紫微斗数）、Thiên Can / Địa Chi（天干/地支）、Thập Thần（十神）；无对应时越南语音译，首见附汉字 | 塔罗小阿尔卡那沿用既有译法 |
| **th-TH** | 中文文化概念无对应：**泰语音译**（如天干 `เจีย`/`อี้`/`ปิ่ง`…）或意译＋音译；塔罗牌名、星座名沿用既有译法，全表锁定同一写法 | 紫微斗数＝ชี่เว่ยตู้ซู่（全表统一，正文复用） |
| **es-ES** | 东方概念用**西语意译＋拼音括号**（Ba Zi、Zi Wei Dou Shu、Tian Gan / Di Zhi）；塔罗牌名用西语既有译名（El Loco、La Emperatriz…）；西语语序与标点规范（¿? ¡!） | 术语表内 `basis` 列记录是否待母语复核 |

### 3.3 易错类目专项

| 类目 | 风险 | 处理 |
| --- | --- | --- |
| 天干 / 地支 | 五语读音各不相同，最易前后不一致 | 全表锁定：ja 汉字保留、ko 汉字音、vi 汉越词、th 音译、es 拼音＋意译 |
| 十神（正官/偏财/食神…） | 意译易丢失「十」的类目属性 | ja/ko 保留汉字，vi/th/es 用本语对应宗教/哲学词汇，首见附原词 |
| 纳音 / 二十八宿 / 二十四山 | 仅中文有系统，外译多为人造 | 优先音译并全线统一；正文首见加括号，禁止逐条临场发挥 |
| 神煞 | 数量多、无通行外译 | 一律按术语表写死，禁止在正文另造 |
| 免责口径（「不构成专业建议」「仅供娱乐与自我觉察」） | 译文易被弱化 | 翻译硬规则内列为不可弱化项，抽检必查 |

## 四、产出与回归

```
build-terms-glossary.mjs   → T07_五语术语表.csv + _terms-coverage.json（无网关注入；--llm 时走网关补全 tier2 五语译名）
```

## 六、待办（母语复核）

术语表 `basis` / `status` 中标注「待母语复核」的条目：th、es 两语的音译选择需母语者确认；复核后把 `basis` 更新为「母语已复核」并将 `status` 置 `filled`。在此之前，正文与 UI 一律以本表为准，保证跨语言一致。
