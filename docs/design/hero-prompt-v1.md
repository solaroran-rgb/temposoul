## 设计决策记录（为什么是这样）

| 决策点 | 定稿 | 否决过的方向 |
|---|---|---|
| 整体色调 | 纯黑 + 青蓝荧光，整体压暗 | 紫粉浅色（v1）、明亮放射银河（v3） |
| 背景星云 | 地平线暗枝杈星云 + 远处弥散星云块 | 大片云雾（像阴天）、亮闪电焦点 |
| 地面 | 粒子格子线框起伏地形，占20% | 直线透视网格、实体山岩、蜿蜒发光道路 |
| 人物 | 极小（1/15画面）、粒子聚合、底部居中、背对镜头面向星云 | 清晰剪影、平视、站中央过大 |
| 构图 | 高视角俯瞰 | 平视地平线 |
| UI | 仅左上标题 + 右上按钮 | 顶栏导航、四大功能卡片 |
| 主题文案 | 「探索命运的节律」 | 不出现排盘/算命功能词 |

## 情感内核

一个对人生迷茫的人（用户自己），站在当下的起点，抬头看这片星空——
他脚下的路起伏曲折（人生非坦途），而他和他所在的城市在宇宙中只是一粒微尘。
命律要做的，是陪他在这浩瀚里探索自己生命的节律。

## 开发阶段对应（视觉→实现）

- 星点+星座：按访问者 IP 经纬度 + 当地时间真实计算（Cloudflare `request.cf` 取经纬度，core 已有 JD/历法层）
- 线框地形：Canvas 2D 粒子网格起伏，零依赖
- 粒子人：Canvas 2D 粒子聚合轮廓
- 性能：星表路由级懒加载，不进结果页
