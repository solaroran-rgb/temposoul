## 3. 能量连接场（全新模块 · Q8 定案 a+b）

老板新 Brief：「通过光影 / 光线连线，展示人与环境、与宇宙之间存在**有规律的**互相影响（能量场、磁场）」。关键词是**规律**——视觉上必须读成几何秩序，不是随机丝线。

| 子模块 | 数量 | 起点 → 终点 | 峰值 alpha | 线宽档 | 约束 |
|---|---|---|---|---|---|
| **a 人 → 天际光线** | **5 – 7 条** | 人形肩部/头顶 → 星座节点 | 0.10 – 0.14 | L5（core 0.9px + halo 2.2px） | 相邻夹角标准差 **≤ 5°**；总张角 ≤ 120°；禁止抖动 > 5° |
| **b 人 ↔ 地标细连线** | **2 条**（左右各一） | 人形腰/膝 → 最近地标轮廓 | 0.08 | L6（core 0.6px + halo 1.4px） | 只连最近 2 个地标，不得交叉 |
| **c 脚下磁力环** | **1 组** | 以人形为心 | ≤ 0.10 | L5 | 半径 = 3× 人形高；刻度 **12 段**；**这是全画唯一的环系** |

- **呼吸动效**：与观察者剪影同相，周期 4.5s、幅度 ±24%（继承主规范 §3.4）。
- **禁止**：任何 < 2s 周期的闪烁；禁止连线在交界带内形成横向连续亮带（穿越交界带时 alpha 强制 ≤ 0.10）。
- **层级归属**：a → L5，b → L6，c → L5。不得占用 L1/L2 名额（焦点唯一律，主规范 §4.3）。

## 4. 地标可辨识度约束（交接卡预警 1 的量化）

20% 带 = 1080p 下 216px、720p 下 144px。要在这么窄的带里让用户认出「体育场 / 高楼 / 湖泊」，只能靠**剪影 + 光点密度**，不能靠细节。

| 约束 | 值 | 理由 |
|---|---|---|
| 可辨识地标总数 | **≤ 5 类**（山脊 / 塔群 / 体育场 / 湖 / 河） | 多于 5 类在 216px 内会糊成一片线 |
| 单栋塔最小宽度 | **≥ 6 px**（@1080p） | 低于 6px 时 core 线宽 1.5px + halo 3.6px 会互相吞并 |
| 塔身表达方式 | 纯线框 + 窗格点阵（点径 1px / 间距 4px / alpha ≤ L5=0.14） | 禁止实体填充（主规范 §2.3） |
| 体育场表达方式 | 单圈椭圆轮廓 + 内部稀疏径向线 ≤ 8 条 | 轮廓即识别，不得画看台细节 |
| 水系表达方式 | 单线河道 + 湖泊闭合轮廓（L3/L4） | 主规范 R5 已要求可辨识 |
| 地形层数 | **≤ 2 层**（近山等高线 L4 + 远山点阵浮雕 L5） | Q6 定案；144px 内第 3 层全是线 |
| 数据来源 | 复用 E2 OSM 城市管线 + 城市库 108,525 城 | 不新建数据源 |

> **实测判定（概念图 N3）**：压缩到 20% 后，山脊、塔群、体育场碗形、湖面、河道 **5 类均仍可辨**，但塔身细节（窗格/棱线分层）已丢失。<span style="color:#39FF14">结论：20% 可行，但必须接受"只有剪影级信息"</span>；建议施工前先出一版 **20% 高度地标线稿试稿**再定稿。

## 7. 差异裁决表增量 R9–R12

### R9 · 交界带（72%–80%）过亮【P0 · 最高优先】

- **现象**：概念图 N3 实测——星空区均亮 7.92、交界带均亮 **18.16**、地貌区均亮 47.11。交界带是星空区的 **2.29 倍**，全画最亮横带出现在地平线附近。
- **根因**：地平线辉光带（`geoEngine` 地平线渐变）+ 星云弥散在近地平处未衰减。
- **修复指令**：① 星云弥散在 y > 0.70 起按 `smoothstep(0.70, 0.80, y)` 衰减至 0；② 地平线辉光峰值 alpha ×0.45，并把峰值位置上移到 y < 0.70（交还给星空区下部）；③ 交界带整体加一层 `multiply` 压暗，目标 ≥94% 负空间。
- **验收**：V24。

### R10 · 天空同心环组数超标【P1】

- **现象**：天空仍见 3–4 组同心圆（参考图 S4 基因的残留）。
- **根因**：S4 会吃掉负空间，与 A1 公理互斥（交接卡冲突 1）。
- **修复指令**：删除全部天空大环（含"层叠大环系"与"月亮轨道环"）；**全画仅保留人脚下 1 组**（L5，alpha ≤ 0.10，刻度 12 段）。
- **验收**：V23。

### R11 · 星座连线过亮【P1】

- **现象**：连线可读成一张"网"，违反新 Brief「很微弱的连线」。
- **根因**：token `cyan-constellation = rgba(77,208,225,0.40)` 是按旧规范定的，与"隐约可见"需求差 5 倍。
- **修复指令**：token 值改为 `rgba(77,208,225,0.07)`（区间 0.06–0.08）；星座节点星点亮度 ≤ L3；**禁止衍射星芒**；星座组数 3–4 组，避开中心 30% 中轴带。
- **验收**：V22。

### R12 · 地貌区可辨识地标不足【P1】

- **现象**：20% 带内塔身细节丢失，只剩剪影。
- **根因**：带高从 34% → 20%，可辨识面积缩减 41%，但地标数量与线宽未同步精简。
- **修复指令**：按 §4 表执行（地标 ≤5 类、塔宽 ≥6px、剪影 + 光点密度表达）；建议先出 20% 高度地标线稿试稿。
- **验收**：V27。
