## 4. 两个必须裁决的正面冲突（本轮最大发现）

### 冲突 1｜环系占天空 vs 负空间 ≥62%

- 基准图纯黑负空间 **~65%**；B 版掉到 **~45%**。
- 掉的原因**不是颜色、不是线宽**，而是 **S4 同心刻度环系统占用了天空区域**——参考图的"高级感"有相当一部分来自大环系，而大环系必然吃掉留白。
- 这是 `SKY-VISUAL-SPEC-v1.md` 公理 A1 与 `SKY-STYLE-DNA-v1.md` G2 的**直接矛盾**，不是执行误差。

**三条可选裁决**：
1. **环系降权**（推荐）：只保留人脚下环（小半径、低 alpha），天空大环整体去掉或降到 α≤0.08 —— 风格感保留约 70%，负空间回到 60%+
2. **环系限量**：天空只留 1 组大环（不是现在的层叠多组）
3. **接受 A1 让步**：把纯黑占比阈值从 ≥62% 下调到 ≥50%，承认"风格优先"

### 冲突 2｜山脉形态：点阵浮雕 vs 等高线线框

- 参考图给的是 **点阵浮雕山体**（有体积感的点云）；基准图要求 **等高线线框山脊**（纯线）。
- B 版自动选了**点阵浮雕**——因为参考图权重更高。
- 影响：点阵浮雕更"厚"、更接近参考图；等高线更"薄"、更接近基准图，也更省渲染开销。

**两条可选裁决**：
1. **混合**（推荐）：近山用等高线线框（薄、显形），远山用点阵浮雕（厚、退晕）——同时拿到纵深和风格
2. **纯点阵**：统一走参考图路线，放弃基准图的山脊语言

## P.5 新增工具教训

1. **图像模型对「几何尺度」指令同样不服从**：明确要求"人物缩到 50%"，连续 3 轮输出均为 **~58%**；且画幅被强制改成 1024×1024 方形（`size` 参数无效）→ 尺度必须交代码。
2. **抹除人物后补背景：4 种算法全部证伪**（矩形线性插值→矩形补丁、biharmonic inpaint→乳白糊斑、整列插值→阶梯条纹、纯径向亮度剖面→同心圆盘）。
3. **可用解法**：自适应各向异性镜像填充 + <span style="color:#39FF14">调和插值亮度校正</span>（Jacobi 迭代）——后者专治"镜像源离辉光中心更远 → 填充区整体偏暗"的**幽灵人形**。
4. **羽化边界位置决定成败**：必须落在 **mask 外缘**（镜像值与原图天然连续处）；落在人物光晕内部会让暗剪影以 ~50% 透明度残留，形成人形残影。

4. **亮度连续性 = 低频亮度场逐像素对齐**：新带的 x 方向低频剖面从「切割线上方实测剖面」线性过渡到「压缩后地面顶部剖面」。
5. 接缝 12 行 alpha 羽化。

## R.4 新增工具教训（重要，已固化进 `ai-image-proportion-enforcer` 技能）

1. **结构冲突要先测再定切割线**：切割线必须高于**所有**地面元素最高点，否则建筑腰斩；若某天空元素（月亮）跨越该线，必须走「抠出 → 压缩 → 原位贴回」，不能指望一条线两全。
2. **补天空不要复制原图内容**：
   - 逐行随机偏移 → 星点被拉成**横向条纹**；
   - 20 行分块偏移 → 块间内容断裂，出现**规整暗块**；
   - 整段偏移 → 段内容本身带 UI 残影同样出暗块。
   → 结论：**唯一干净解是程序化生成**（同分布重采样）。
3. **亮度衔接不能用「整行均亮」**：整行均值会被横向暗区拉低，校正后局部反而出现**方形暗块 / 横向暗带**。正确做法是 **x 方向低频剖面逐像素对齐**，且参考基线取**紧邻切割线的 4 行**（取宽了会残留台阶）。
4. **叠加光柱剖面只取正增量**（`max(P − p25, 0)`）；用 `P − mean(P)` 会在光柱两侧造出负值 → 方形暗块。
5. 素材段必须**用代码扫描 UI 行**确认净空，目视定位连续出错 3 次（按钮区 333–415 被误当净空天空）。
