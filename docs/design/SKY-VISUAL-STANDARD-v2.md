## 1. 视觉北极星（North Star）—— 唯一裁判

> **这不是"数据可视化"，这是一张「人在宇宙中渺小」的数字哲学海报；数据只是它的颜料，不是它的目的。**

| # | 公理 | 可判定表述 |
|---|---|---|
| **A1** | **黑是主角，光是客人** | 全画纯黑（亮度 < L*8）占比 **≥ 62%**；任一 64×64 像素块平均亮度 ≤ L*45。 |
| **A2** | **层级分明，无平铺** | 必须一眼读出「星空 > 地貌 > 城市 > 人物 > 细节」五级层次，相邻两级峰值亮度差 **≥ 25%**。**禁止所有元素同一亮度平铺**。 |
| **A3** | **克制高于丰富** | 每新增一个视觉元素，必须先移除或压暗一处已有元素；**净视觉复杂度不得增加**。 |

**A2 是三条里最要命的一条**：`p1b` 的死因就是整个地面区以同一亮度（`uColorCore` #00E5FF）平铺，山/建筑/水系/植被亮度全等，读起来是"一坨青蓝色的东西"。

## 3. 构图模板 CT-1（本规范核心）

### 3.1 竖直分区（替代旧 §4.1 全部版本）

以基准视口 **1920×969（1.981:1）** 为准：

| # | 分区 | 像素范围 | 画高占比 | 内容 | 亮度目标 |
|---|---|---|---|---|---|
| ① | **天空区** | 0 – 494 | **50.98%** | 星野、星座、月亮、星云、中轴光柱、品牌 UI | 大面积纯黑 + 稀疏亮点 |
| ② | **补天带** | 494 – 659 | **17.03%** | 星空延续（程序化生成，与①无缝） | 与①同族，**不得更密更亮** |
| ③ | **地貌区** | 659 – 969 | **31.99%** | 山脊、城市天际线、水系、体育馆、人物 | 亮度自下而上递减 |

- **①+② = 天空 68.01%**；**③ = 地貌 31.99%**。
- ①②③ 是**构造概念**（源自 R1 的合成方式），对 WebGL 落地而言只有一条线重要：**地平线 y = 68%**。①/② 的分界（494）**仅约束概念图与合成流程**，WebGL 直出无需实现。
- **容差**：地平线 **68.0% ± 1% 画高**（1920×969 = ±9.7px）。
- **禁止**把地平线糊成一条横向连续亮带——但见 §3.6 已知残留（CT-1 承认地平线辉光带存在）。

### 4.2 面积配额（硬约束，可测量）

| 色彩族 | 配额 | 测法 | CT-1 实测 |
|---|---|---|---|
| 纯黑 | **≥ 62%**（A1） | 亮度 < L*8 占比 | 46.7% 🟡（概念图层，见 C3） |
| 青蓝族（core+glow+dim+constellation） | ≤ 30% | 饱和度 > 0.2 且色相 175°–200° | — |
| 白 / 近白（文本 + 星点核） | ≤ 7% | 亮度 > L*85 占比 | 3.2% ✅ |
| **暖橙** | **≤ 0.8%，且聚为 1 簇** | 色相 15°–45° 占比 + 连通域数 = 1 | **0.03%** ✅ |

- **暖橙配额历史教训**：`geoEngine.ts` 曾在 101 塔尖 **+ 塔身**打两个焦点（`pWarm.push` ×2，size 6.0）。基准图**全画只有一处**暖色微光。**规定：全画暖橙焦点数量 = 1**（多点时必须视觉聚合为单簇，簇内最远点距离 < 3% 画宽）。
- **WebGL 目标态下限推导**：天空区（68%）纯黑 ≥88% + 地貌区（32%）纯黑 ≥12% → 全画 **≥ 63.7%**，A1 成立。**主约束因此从"地貌区负空间"转为"天空区纯黑 ≥88%"。**

### 4.3 禁止项（硬禁令）

❌ 大面积暖色 / 杂色 / 紫红 / 绿 ｜ ❌ 写实照片、3D 实体渲染、立体曲面 ｜ ❌ 实体填充面（唯一例外：粒子聚合形成的视觉密度） ｜ ❌ 阴影 / 外部光源 / 明暗立体光影 ｜ ❌ 卡通 / 手绘 / 油画 / 水彩 ｜ ❌ 模糊、噪点脏乱 ｜ ❌ 文字扭曲乱码、水印、LOGO、边框画框、设备样机 ｜ ❌ 恐怖符号（血月、破碎、发光眼睛、骷髅、灾难意象） ｜ ❌ < 2s 周期的闪烁动效（游戏化，用户明确否决）

## 5. 亮度层级与光效体系（一切参数的推导源）

### 5.1 六级亮度层级（L1 最亮 → L6 最暗）

**所有线宽 / 透明度 / 取色必须从这张表推导，不得单独指定。**

| 层级 | 名称 | 视觉角色 | 峰值 alpha | core 线宽 | 光晕半径 | 颜色 | 对应对象 |
|---|---|---|---|---|---|---|---|
| **L1** | 焦点 | 全画唯一视觉锚点 | 1.00 | — | — | `accent-warm` | 月亮（暖色，粒子 size 6.0） |
| **L2** | 主体 | 目光首先落到的实体 | 0.72 | 2.4 | 6.0 | `cyan-core` | 地标棱线 / 主塔轮廓 |
| **L3** | 次体 | 主体周围的城市肌理 | 0.42 | 1.5 | 3.6 | `cyan-core` × 0.72 | 城市建筑轮廓（近/中） |
| **L4** | 环境 | 大地骨架，托住城市 | 0.26 | 1.2 | 3.0 | `cyan-dim` 提亮版 | 山脊等高线 / 水系主线 |
| **L5** | 纹理 | 大地的呼吸，几乎不抢戏 | 0.14 | 0.9 | 2.2 | `cyan-dim` × 0.65 | 道路 / 地表扭曲线 / 远山 / 能量连线 a、c |
| **L6** | 星尘 | 氛围，感知得到但看不清 | 0.07 | 0.6 | 1.4 | `grid-dark` 级 | 地面栅格 / 浮尘 / 极远细碎 / 能量连线 b、星座连线 |

**层间硬约束**：相邻层峰值 alpha 比 **≈ 1.7×**（0.07→0.14→0.26→0.42→0.72→1.00 的近似几何级数）。**连续三层不得为同一 alpha。**

**为什么是 1.7×**：人眼在纯黑底上的 Weber 辨别阈值约 12–18%。层间差 < 1.3× → 肉眼无法区分（画面变"平"，`p1b` 的病）；> 2.5× → 中间层断层（主体浮空）。1.7× 落在可辨与连续的交集，且 0.07 × 1.7⁵ ≈ 0.99 恰好覆盖全动态范围。**推论：任何一层调亮/调暗超过一档，必须同步检查相邻层。**

### 5.2 光晕（glow）规范

| 参数 | 规范值 | 判定 |
|---|---|---|
| `glowRadiusPx / coreWidthPx` | **2.2 – 2.6** | ✅ 结构正确（L2: 8.0/3.6=2.22） |
| `uCoreRatio` | 0.28 – 0.34 | ✅ |
| `uCoreAlpha : uGlowAlpha` | **2.6 : 1**（建议 0.9 : 0.35） | 🟡 |
| 光晕衰减曲线 | `exp(-x²·k)`，k = **5.0** | ✅ 保留 |
| 混合模式 | `AdditiveBlending` 全层 | ✅ |
| `depthWrite` | 全层 `false` | ✅ |

> **关键裁定：光晕是"呼吸"的来源，不是"亮度"的来源。** 想让对象更亮，**先调 `uCoreAlpha`，不要调 `glowRadiusPx`** —— 加大光晕半径只会让画面糊。`p1b` "糊成一团"的高度嫌疑即此。

### 5.3 呼吸动效

| 对象 | 周期 | 幅度 | 依据 |
|---|---|---|---|
| 观测者剪影粒子 | 4.5s | ±24%（0.5 ± 0.12） | `SkyScene.ts:512` `sin(t*1.4)` ✅ |
| 星点闪烁 | — | ±10%（`twinkleAmp` 0.10） | ✅ |
| 星云团块呼吸 | 18s | ±15% | `sin(t*0.35)` ✅ |
| 能量连接场 | 与剪影同相 | ±24% | 见 §6.5 |

### 5.4 星点分层

| 参数 | 规范值 |
|---|---|
| 星等阈值 `uMagLimit` | 6.0 |
| 星点大小 | 按星等**非线性**映射，最亮 : 最暗 ≥ **3.5 : 1** |
| 星点颜色 | 白 `#FFFFFF`（亮星）→ 青白（中）→ `cyan-dim`（暗星），按 BV 色温 + 星等双因子 |

| 地平线淡出 | `smoothstep(-0.015, 0.02, y/500)` ✅ 保留 |
| **天空区纯黑** | **≥ 88%**（CT-1 主约束，见 §4.2） |

## 6. 元素模块规范

### 6.1 星野
稀疏、**大小与亮度分级**（非均匀撒点）；星点密度**不得**在补天带/近地平处升高；全画星点核总占比 ≤ 7%。

### 6.2 星座
| 参数 | 值 |
|---|---|
| 组数 | **3 – 4 组** |
| 连线 alpha | **0.06 – 0.08**（token `cyan-constellation` = `rgba(77,208,225,0.07)`） |
| 节点星点亮度 | **≤ L3** |
| 衍射星芒 | **禁止** |
| 标签 | **仅中文**（去掉英文副标）；alpha 0.5 – 0.7；11–12px |
| 位置 | 天空区上半部，避开中心 30% 中轴带 |

### 6.3 月亮
真实天文优先（**接受某些时刻画面无月亮**）；左上/右上象限，**不得与人形同轴**；暖色 `#F0C878`，占比 ≤ 0.8%（CT-1 实测 0.03%）；**无轨道环**（天空环系 = 0 组）；相位纹理按星历（原 R8）。

### 6.4 中轴光柱
| 参数 | 值 |
|---|---|
| 位置 | **x = 50%** |
| 起止 | 天顶(y=0) → 人形脚部 |
| 宽度 | 顶部 8px → 底部 2px（渐宽） |
| alpha | **≤ 0.10** |
| 穿越地平线辉光带 | α **强制 ≤ 0.10** |
| 混合 / 默认 | Additive；**保留开启**（Q4 定案） |

### 6.5 能量连接场（Q8 定案 a+b+c）
老板原话：「通过光影 / 光线连线，展示人与环境、与宇宙之间存在**有规律的**互相影响（能量场、磁场）」。关键词是**规律** —— 必须读成几何秩序，不是随机丝线。

| 子模块 | 数量 | 起点 → 终点 | 峰值 α | 层级 | 约束 |
|---|---|---|---|---|---|
| **a 人 → 天际光线** | **5 – 7 条** | 人形肩部/头顶 → 星座节点 | 0.10 – 0.14 | L5 | 相邻夹角标准差 **≤ 5°**；总张角 ≤ 120°；禁止抖动 > 5° |
| **b 人 ↔ 地标细连线** | **2 条**（左右各一） | 人形腰/膝 → 最近地标轮廓 | 0.08 | L6 | 只连最近 2 个地标，不得交叉 |
| **c 脚下磁力环** | **1 组** | 以人形为心 | ≤ 0.10 | L5 | 半径 = 3× 人形高；刻度 **12 段**；**全画唯一环系** |

呼吸与剪影同相（4.5s / ±24%）。**禁止**连线在辉光带内形成横向连续亮带。**不得占用 L1/L2 名额**（焦点唯一律）。

### 6.6 城市天际线
| 约束 | 值 |
|---|---|
| 可辨识地标总数 | **≤ 5 类**（山脊 / 塔群 / 体育场 / 湖 / 河） |
| 单栋塔最小宽度 | **≥ 6 px**（1920 宽下）—— 低于 6px 时 core 1.5px + halo 3.6px 会互相吞并 |
| 塔身表达 | **纯线框 + 窗格点阵**（点径 1px / 间距 4px / α ≤ L5=0.14）；**禁止实体填充** |
| 体育场 | 单圈椭圆轮廓 + 内部稀疏径向线 ≤ 8 条；**轮廓即识别**，不画看台细节 |
| 层级 | 按 §5.1 归 **L3**，`uCoreAlpha` 0.42 / `glowRadiusPx` 3.6 / `coreWidthPx` 1.5；base 色按距离分级（近 `cyan-core`×0.72，远 `cyan-dim`） |
| 验收 | 可数出 **≥ 15 栋**独立建筑轮廓；该区 64×64 块平均亮度 ≤ L*45 |
| 数据源 | 复用 E2 OSM 城市管线 + 城市库 108,525 城 —— **不新建数据源** |

### 6.7 山脊 / 地形
**地形层数 ≤ 2 层**（Q6 定案）：近山等高线（L4）+ 远山点阵浮雕（L5）。
三条 band 的 layer = **0.42 / 0.28 / 0.15**（远暗近亮，全部落在 L4–L5），山头颜色用 `cyan-dim`（**不是** `uColorCore`）。
维持 `y < 14` 的 z 过滤（防遮挡，属已修复项，勿动）。塔尖允许越过地平线，越线高度 **≤ 3% 画高**。

### 6.8 水系 / 道路
水系归 **L4**（α 0.26 / 1.2px / `cyan-dim`）；道路归 **L5**（0.14 / 0.9px）。
`cyan-dim` = #008B99 本身很暗，Additive 下几乎不可见 → 用「`cyan-dim` × 1.35 提亮」的**等效色**（≈ #00BCCF），**不能直接改 token**（`cyan-dim` 还被网格复用）。
验收：水系与其相邻地表亮度差 ≥ L*6。

### 6.9 点阵（粒子）用法
**小剂量，仅窗格**（Q5 定案）：点径 1px / 间距 4px / α ≤ L5。**禁止大面积地形点阵**。
人形若用粒子构成：点数 900、`size 0.9`、密度按到轴心距离 1/d 衰减、**不画闭合轮廓**、脚部 10% 点数翻倍（接地感）。

### 6.10 星云
blob 数量 **≤ 9**（A3 减法）；alpha 上限 **0.15**；必须叠**分形噪声遮罩**（禁止 `createRadialGradient` 直填的硬边贴片感）；**只蒙天空区上部**（y ≤ 0.70），`smoothstep(0.70, 0.80, y)` 衰减至 0。
验收：星云边缘 alpha 梯度跨度 ≥ 画宽 12%（无 < 2% 宽的硬边）。
