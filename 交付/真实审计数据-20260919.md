## 三、视觉硬伤（真实截图证据）

### T0 · 首页星空首屏
- **截图**：`shots/home_desktop.png`、`shots/home_mobile.png`
- **现状**：首页 hero 是灰色占位块（`sky-emotion-hero`），文字"☽ 这是你出生时的真太阳时星空"+ "每一颗星星，都是那一刻宇宙给你的第一份礼物"
- **代码位置**：`src/pages/InputPage.tsx:574-592`
- **问题**：**未渲染真实出生时星空图**，只有文字 + 渐变色块。T3 排盘仪式要求"星空首屏 + 3 秒淡入"，现状只有渐变色 + 文案。
- **修复**：接入 `StarfieldBackground.tsx`（canvas 组件，92 行已存在）或 `SkyMap.tsx`（已有 `starfield.ts` 库）。

### T3 · /result 无参态
- **截图**：`shots/result_desktop.png`
- **现状**：无参访问 /result 显示"命主·男"+"年月日·时辰索引"全空，有一堆问题钩子 + CTA，但**无四柱命盘**
- **问题**：违反 T3 "排盘仪式"——空态应有"请先输入出生信息"引导，而非半空态
- **修复**：无参时 redirect 到 `/` 或显示引导页

### T6 · /pricing 定价页（核心转化页）
- **截图**：`shots/pricing_desktop.png`
- **现状**：**完全无 CSS**——裸文本堆叠 + 白底 + 标题"选择适合您的命理探索方案"左侧溢出
- **代码**：`src/pages/platform/PricingPage.tsx`（143 行，有完整 `pricing-card` class）
- **根因**：**全项目 0 个 CSS 定义 `pricing-card`**，且 PricingPage 不 import 任何 CSS
- **影响**：**T6 核心转化页视觉断裂**，白底与全站暗色不一致
- **修复**：新建 `src/pages/platform/PricingPage.css` 或在 `styles.css` 加 `pricing-card` 样式（参考 M0 报告的"视觉规范"）

### 移动端顶部导航

- **现状**：语言切换按钮（中文/English/日本語/한국어/Tiếng Việt/ไทย/Español）与"登录"按钮**重叠堆叠**，导航文字挤压溢出
